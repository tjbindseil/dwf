# Weekly Release Checklist

## Quality Gates
- [ ] Unit tests pass for changed modules
- [ ] Integration path manually validated with 2+ clients
- [ ] Critical failure modes tested (disconnect/reconnect, duplicate events)
- [ ] Performance spot-check completed (latency + UI responsiveness)

## Product/UX
- [ ] Room create/join flow verified
- [ ] Image upload validation errors shown clearly
- [ ] Undo/redo behavior verified per user ownership
- [ ] Export PNG produces expected composed image

## Operational
- [ ] Decision log updated for key tradeoffs
- [ ] Open defects triaged and severity-tagged
- [ ] Demo notes prepared
